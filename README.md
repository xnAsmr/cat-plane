# 喵机长 · 云端巡航

一个零依赖的单页动态 HTML 作品：一只戴着飞行护目镜的橘猫机长，驾驶小飞机穿行在云层与远山之间。页面结构、样式、插画与交互全部收纳在 `index.html` 中，可离线运行。

## 快速开始

无需安装依赖，也无需构建：

- 直接双击 `index.html`，用浏览器打开即可；
- 或在本目录启动一个静态服务器后访问 `http://localhost:8000`：

```powershell
python -m http.server 8000
```

## 功能

- **三种天空主题**：白昼、黄昏、夜航（含月亮与星空），切换时天空、云、远山与界面配色平滑过渡。
- **加速飞行**：螺旋桨与云层提速、机身前倾、速度线增强，仪表盘航速平滑上升并可随时减速。
- **持续动效**：螺旋桨旋转、机身起伏、猫咪眨眼与抖耳、尾巴摆动、围巾飘动、机尾气流、速度线、星光闪烁。
- **鼠标交互**：移动鼠标（或触摸拖动）产生云层、远山与飞机的多层视差；点击天空会撒出一片小星星。
- **飞行仪表**：实时变化的高度、航速与速度条。
- **适配性**：窄屏响应式布局，并遵循系统的「减少动态效果」偏好。

## 技术实现

- **插画**：内联 SVG 绘制飞机与猫咪，不依赖任何图片资源。
- **主题**：CSS 变量配合三个叠加的渐变图层，实现可平滑过渡的白天 / 黄昏 / 夜空。
- **动画**：CSS `@keyframes` 驱动全部循环动效，统一由 `--rate` 变量控制播放倍率。
- **交互**：原生 JavaScript 生成云朵、星星与速度线，处理主题切换、加速、视差、点击粒子与仪表盘数值。
- **零依赖**：不引用外部字体、CDN 或第三方库，单个 HTML 文件即可完整运行。

## 自定义

| 想改的内容 | 修改位置 |
| --- | --- |
| 天空、云、远山、界面配色 | `:root` 与 `[data-theme="..."]` 中的 CSS 变量 |
| 动画快慢与加速倍率 | `.scene` 的 `--rate`、`.scene.boost` 的覆盖值 |
| 猫咪与飞机造型 | `index.html` 中 `svg.plane` 内的路径与渐变 |
| 标题、按钮、仪表盘文案 | `.ui` 区域的 HTML 文本 |

## 浏览器支持

支持 Chrome、Edge、Firefox、Safari 等现代浏览器。页面使用了 `backdrop-filter`、`clip-path`、`transform-box`、`100dvh` 等较新的 CSS 特性，建议保持浏览器为较新版本。
